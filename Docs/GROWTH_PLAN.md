# Starship Lander — Organic Growth Plan (Revised, v2.1.0)

## Context
- Studio: Solo developer + 2 AIs (Claude Code + ChatGPT)
- Budget: <$50
- No in-house art or screenshot design skills
- Goal: Increase organic App Store downloads
- Constraint: Growth must be AI-driven, low-effort, sustainable
- Primary channel: App Store Optimization (ASO)

---

## 0. Baseline Changes Already Made

### Promotional Text — Updated

Previous positioning: Generic space / landing / simulator framing

Current promotional text (canonical):
> "A skill-based landing game where precision beats luck. Master thrust, gravity, and control across the solar system."

Reason for change:
- Explicitly communicates skill > luck
- Signals precision and mastery
- Filters casual players
- Attracts the correct hardcore / skill-based niche

**This positioning must be treated as canonical going forward.**

### Keywords — Updated

Current keyword set:
`lander, physics, precision, skill, thrust, flight, descent, control, challenge, hardcore, starship, simulator`

Key changes:
- Added: precision, skill, hardcore
- Reduced generic space framing
- Shifted focus to physics mastery and challenge

**All future copy must reinforce these concepts.**

---

## 1. Core Growth Principle

App Store visibility comes first.

Every action must:
- Improve App Store conversion
- Increase search relevance
- Reinforce skill-based differentiation

Social media is secondary and must feed ASO, not replace it.

---

## 2. App Store Optimization (Top Priority)

ASO Rules:
- Review promotional text and keywords every 2–3 weeks
- Update copy when:
  - New mechanics ship
  - Difficulty or scoring changes
  - Competitive features expand (GC, ranks, achievements)

Claude Responsibilities:
- Propose revised promotional text when features change
- Suggest keyword swaps if positioning shifts
- Keep tone skill-focused, concise, confident

---

## 3. Screenshot Strategy (No Art, <$50)

Objective: Create high-converting screenshots using only in-game assets.

Tools (Free): Keynote (preferred), Canva (free tier), macOS Preview (fallback)

Rules:
- No illustrations
- No custom art
- Gameplay must be visible
- Large, bold text overlays only

### Screenshot Set (Exactly 5)

1. **Precision Beats Luck** — Tight landing, HUD visible
2. **Master Thrust & Gravity** — Mid-air control moment
3. **10-Planet Campaign** — Visually different environments
4. **Global Leaderboards** — Galaxy Rank / Top Pilots visible
5. **One Mistake = Crash** — HARD / FAIL state

Claude Responsibilities:
- Provide exact caption text for each screenshot
- Suggest one alternate caption per screenshot for future refreshes
- Keep captions under ~6–8 words

---

## 4. In-Game Viral Loop (Critical)

Primary Growth Engine: Share Score Card

Current state: Feature exists, passive usage.

**Required behavior: Sharing must be event-driven, not optional.**

Trigger share prompt on:
- New personal best
- New achievement unlocked
- Galaxy Rank improvement

Baseline share copy:
> "New personal best 🚀 Think you can land better?"

Claude Responsibilities:
- Generate 2–3 alternative share captions
- Keep copy competitive, not promotional
- Avoid spammy tone

Each share must:
- Show real gameplay results
- Target skill-driven players
- Require zero manual effort from the developer

---

## 5. Social Media (Strictly Limited)

Rule: No broad social strategy unless it amplifies ASO.

Approved channel: Reddit only

Target subreddits:
- r/iosgaming
- r/IndieGames
- r/GamePhysics (occasional)

Frequency:
- Once every 3–4 weeks
- No weekly cadence
- No cross-post spam

Allowed framing:
> "I built a physics-based rocket landing game focused purely on skill — no upgrades, no luck. Recently added global leaderboards and achievements. Looking for feedback from players who enjoy hard games."

Claude Responsibilities:
- Draft subreddit-specific variants
- Respect subreddit rules
- Avoid marketing language

---

## 6. Weekly Challenges — Deferred

Decision: Do NOT implement weekly challenges now.

Reason:
- Requires critical mass
- Below ~200 DAU → low engagement
- High effort, low return

Revisit only if:
- DAU reaches ~200+
- Active leaderboard competition exists

---

## 7. AI Division of Labor

| Role | Responsibilities |
|------|-----------------|
| **Claude Code** | Maintain stable releases, implement light growth hooks (share triggers, UX prompts), maintain Game Center stability, no experimental growth features unless requested |
| **ChatGPT** | ASO copy revisions, screenshot captions, share card text, Reddit drafts, feature framing |
| **Human (Developer)** | Ship builds, capture screenshots, approve copy, final decisions |

---

## 8. Success Metrics

Primary:
- App Store impressions
- Page view → install conversion

Secondary:
- Share card usage
- Leaderboard participation
- Retention of skill players

Ignore vanity metrics unless they convert.

---

## 9. Long-Term Philosophy

Starship Lander is: skill-based, niche, competitive.

Growth will be: slow initially, stable, compounding per update.

Every feature must:
- Reinforce mastery
- Encourage replay
- Enable comparison (scores, ranks, achievements)
